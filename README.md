# go-startup-agile

창업과 린·애자일 경영을 AI 튜터와 함께 익히는 학습 워크스페이스입니다. 창업을 준비하는 사람, 초기 회사를 운영하는 사람, 회사 안에서 신사업을 맡은 관리자를 위해 만들었습니다.

문제 정의·고객 발견·MVP·PMF 같은 린 스타트업 방법, 스크럼·OKR로 조직을 운영하는 법, 벤처기업법·중소기업창업 지원법·벤처투자법·상법 같은 국내 제도, 투자유치(조건부지분인수계약·RCPS·텀시트·캡테이블)를 다룹니다. 국내 제도를 뼈대로 하고, 미국 Delaware 법인·SAFE·NVCA 문서 같은 글로벌 기준과 비교합니다.

정해진 강의 자료는 없습니다. 이 리포에는 커리큘럼의 큰 지도와 튜터의 행동 규칙만 있습니다. 도식과 조사 자료를 담은 HTML은 대화하면서 튜터와 함께 그 자리에서 만들고, 실무 산출물(실험 계획, 지원사업 로드맵, 스톡옵션 설계 메모, IR 내러티브 등)은 내 사업을 재료로 직접 씁니다.

> 튜터는 법률·세무 자문을 하지 않습니다. 법령과 지원사업 조건은 세션마다 공식 출처에서 다시 확인하고 출처와 날짜를 알려 줍니다. 확인하지 못하면 확인하지 못했다고 말합니다. 실행 전에는 전문가에게 확인하세요.

## 시작하기

준비물은 Git, [GitHub CLI](https://cli.github.com)(`gh`), Claude Code 또는 Claude Desktop입니다. 비공개 리포이므로 먼저 GitHub에서 보낸 초대를 수락하고, 터미널에서 `gh auth login`으로 로그인합니다. 다른 설치는 필요 없습니다.

```bash
cd ~/Desktop
gh repo clone holmesLee-ws/go-startup-agile
```

**Claude Code**

```bash
cd ~/Desktop/go-startup-agile
claude
```

처음 열면 이 폴더를 신뢰하는지 묻습니다. 기본 선택은 「No, exit」이므로 Enter만 누르면 종료됩니다. **아래 화살표로 「Yes, I trust this folder」를 고른 뒤 Enter**를 누르세요. 그래야 학습 기록 저장과 자료 조사를 튜터가 묻지 않고 진행합니다.

**Claude Desktop**

Code 탭에서 데스크탑의 `go-startup-agile` 폴더를 선택합니다. Windows에서는 데스크탑이 OneDrive 아래(`OneDrive\Desktop`)에 있을 수 있습니다. Chat 탭이 아니라 Code 탭이어야 튜터 규칙이 적용됩니다.

어느 쪽이든 「안녕」이라고 입력하면 시작합니다.

## 이렇게 진행됩니다

1. 무엇을 하려고 배우는지(창업 준비, 운영 중, 사내 신사업), 경험은 어떤지 짧게 묻고, 제품·조직·제도와 자본 세 묶음에서 문제를 하나씩 풀어 출발점을 찾습니다. 아이디어만 있는 단계라면 이 과정은 생략합니다.
2. 모듈마다 먼저 상황 문제로 수준을 확인합니다. 이미 아는 내용이면 바로 넘어갑니다. 경험이 많다는 말만으로는 넘어가지 않고, 문제로 확인합니다.
3. 필요한 부분은 튜터와 대화하고, 내 답을 반영한 HTML을 함께 만들어 가며 익힙니다. 모듈을 마치면 내 사업에 쓸 메모·계획서 초안이 `learner/work/`에 남습니다.
4. 튜터는 내 답을 보고 너무 빠른지, 보강이 필요한지, 지루한지 판단해 속도와 방식을 바꿉니다.
5. 다음에 다시 열면 기록을 읽고, 지난번 답하지 않은 질문이 있으면 그것부터, 복습할 때가 된 모듈이 있으면 복습 질문 하나로 이어갑니다.

언제든 그냥 말로 요청하면 됩니다. 「이건 넘어가자」, 「너무 어려워」, 「그림으로 보여 줘」, 「우리 회사 상황으로 해 보자」처럼요.

| 명령 | 하는 일 |
|---|---|
| `/learn [모듈 또는 주제]` | 시작하거나 이어가기 |
| `/check [모듈 또는 영역]` | 빠르게 수준 확인하고 건너뛰기 |
| `/map` | 지금까지의 현황과 다음 모듈 |
| `/pace [너무 빠름·너무 느림·지루함·어려움]` | 속도와 난도 바꾸기 |

## 구성

| 위치 | 내용 |
|---|---|
| [curriculum/map.md](curriculum/map.md) | 커리큘럼 지도(P 문제와 고객, L 린 실험, A 애자일 조직, K 창업 제도와 법, F 투자유치, X 졸업) |
| [CLAUDE.md](CLAUDE.md), [tutor/](tutor/) | 튜터의 행동 규칙. 법령 확인 규칙은 [tutor/sources.md](tutor/sources.md) |
| `.claude/` | 명령과 권한 설정 |
| `learner-template/` | 학습 기록의 빈 양식 |
| `learner/` | 내 기록, 내 HTML, 내 실무 산출물. 처음 시작할 때 생깁니다 |

`learner/`는 Git에서 제외되어 내 컴퓨터에만 남습니다. 그래서 `git pull`로 커리큘럼을 업데이트해도 기록이 충돌하지 않습니다. 컴퓨터를 옮길 때는 이 폴더를 직접 복사하세요.

다른 경영 영역(가치평가, 재무, 회계, 세무, 인사, 법무, 마케팅, 프로덕트 등)과 겹치는 주제는 여기서 창업 결정에 필요한 깊이까지만 다루고, 튜터가 어느 go-* 워크스페이스에서 깊게 다루는지 알려 줍니다.

## 튜터가 쓰는 권한

튜터는 묻지 않고 내 학습 기록, `learner/studio`의 HTML, `learner/work`의 Markdown을 쓰고, 웹을 조사하고, 만든 HTML을 열 수 있습니다. 그 밖의 파일을 고칠 때는 평소처럼 허락을 구합니다. 웹 조사 때는 질문과 주소가 외부 서비스로 전달되므로, 회사 기밀이나 개인정보는 대화에 넣지 마세요. 숫자가 필요하면 바꾼 값으로 충분합니다.
